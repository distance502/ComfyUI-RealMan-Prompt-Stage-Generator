# 真男人提示词阶段生成器

`ComfyUI-RealMan-Prompt-Stage-Generator` 是一个面向 ComfyUI 的阶段式提示词生成节点。它将标签选择、随机主题、模板风格、智能文本、独立视频提示词 Skill、本地/API 模型、设定图反推、标签块编排、NSFW 工作台、历史记录和严格去重整合到同一节点中。

## 主要功能

- 高级按钮直接读取后端完整目录，提供 90+ 模板风格与 110+ 随机主题方向；长目录使用下拉选择，不再被前端旧短名单截断，并补齐风格隔离、智能文本优先、极限随机和提示词优先等控制。
- 图像提示词统一输出带剧情的自然语言；每条都会形成“处境与动机、事件触发、主体回应、局势升级、情绪转折、环境与光线反馈、视觉高潮、开放定格”的视觉链路。中文与英文成品均不设字数上限或下限，长度由剧情、空间关系和可见细节决定。主提示词、智能文本、标签块、角色设定图、仅 Skill、本地模型、API 和模型后置共用同一图像剧情合同；模型短草稿会融入 Skill 剧情骨架，思考/分析包装会先清洗。内置 Qwen3.5 中文后置采用 2-4 句增量润色并融合回 Skill 长段底稿，避免 4B 模型把输出预算耗在整篇重写。多 `choice`、Responses API 和对象式正文均可解析；首次空文本或只有分析/占位符时会自动重试一次，仍不可用才回退。
- 本地 Qwen、Gemma、Llama、Mistral、DeepSeek 与通用 GGUF 会优先采用模型自带聊天模板；模板状态缺失或无效时按模型系列选择兼容格式并只重试一次，避免 `Invalid chat handler` 直接使图片和视频提示词回退到 Skill。
- 智能编排 v12 会追踪运行时随机派生标签的来源。若随机场景与随机动作、道具或光影形成明确的物理冲突，只移除可证明来自随机侧且未锁定的标签并重建关系图；用户显式选择和保护白名单永不被静默改写。
- 智能编排 v13 会把自然语言中的明确排除项作为随机结果的否决条件：“不要城市和列车，故事发生在森林”会清除随机产生的城市/列车锚点，并让图片、智能文本与视频统一回到森林主场景。具体排除词只删除对应随机元素，不会误删同世界族的其他内容；手动选择与排除要求互相冲突时仍保留手动标签并进入保护策略。
- 智能编排 v14 支持正向主场景接管随机场景：“故事发生在森林”“主要场景设在古城”等明确句式无需额外写“不要”，即可移除不兼容的随机地点；古城与神殿等已登记的兼容世界仍可共存。普通叙事只是先后提到多个地点时不会触发强制接管，手动场景冲突也只报告而不删除。
- 智能编排 v15 会把明确主场景继续传播到动作、道具、光影和自定义补充：森林主场景若随机混入列车、控制台或霓虹街区，会只移除这些可证明来自随机且未保护的跨世界锚点，同时保留火炬等兼容元素。自然语言否定与主场景规则命中同一标签时只诊断一次；手动或锁定的跨世界标签仍不会被静默改写。

### 性能与交互优化

- 节点元数据不再为 200 个隐藏槽位重复携带完整标签目录，添加节点、打开工作流和加载 `/object_info` 更轻量；旧工作流保存的标签字符串仍兼容。

### 标签容量与提示词逻辑

- 标签面板的 10 个分组现在每组提供 20 个可选槽位，旧工作流原有的前 10 个槽位名称保持不变；载入旧工作流时新增槽位自动填为“无”，不会挤乱后续设置。
- 标签弹窗会显示每组 `已选/上限`，达到上限后保留已选标签的取消能力，并把溢出标签明确放入“自定义补充”而不是静默丢弃。槽位面板、预设、NSFW 映射、随机器和状态归一化使用同一份容量配置，内部仍有 32 个槽位硬保护。
- 扩容不会让随机模式无边界地堆标签：随机自动补充最多沿用每组前 10 个自动槽位的预算，弱/中/强分别补 1/2/剩余容量；新增槽位主要用于人工选择、预设和 NSFW 映射。提示词仍使用 32 个自然语言片段预算，并按主体、场景、构图和安全约束优先级收敛，避免把 200 个可选槽位直接拼成标签串。
- 风格隔离作用于全部生成模式，与“运行时随机”是否开启无关。显式模板拥有主媒介；自动模板配合具体主题池时，由主题池档案确定一个主轨道。严格模式清除所有外来媒介词，平衡模式最多保留一个兼容质感桥，允许漂移模式最多保留一个有意的次风格。
- 最终归一化后会冻结一份本次 `全局创作主线`：模板负责媒介，主题池负责题材与地点，主体、服装、场景、动作和画面结构成为事实锚点。Skill、标签块、智能文本、内置 GGUF、外接本地模型与 API 都读取同一份主线；模型若另起水彩/CG/摄影媒介或宫殿/都市/机库等冲突场景，会先尝试把可用细节融合回 Skill 剧情，仍冲突就保留 Skill 成品。该合同及摘要会写入 JSON 的 `global_creative_spine` 与 `global_creative_spine_summary`，方便排查串词。
- 智能编排 v11 让风险策略实际控制模型调用：水下持续明火等未解决强语义冲突无法在不改写显式选择的前提下安全润色，因此图像、智能文本和视频会直接保留已校验 Skill 成品，不再调用本地/API 模型后等待回退。终端与 JSON 会分别记录智能跳过次数、原因及视频状态；普通可解决关系仍按 v10 的增量融合或保守整理策略调用模型。
- 智能编排 v10 不只读取开关，也会理解自然语言中的角色三视图、视频分镜、非人物产品/建筑等任务信号，并分别记录正向与负向证据；“不要三视图但要视频提示词”“not a video prompt but a character sheet”“场景里没有列车”等否定与转折表达不会误触发前半句模式或世界族。关系图会同时读取当前标签和自然语言场景；即使标签解析遗漏地点，也会从“城市天台”“森林小路”等正文收紧世界族，并用否定范围排除“不是城市街道”这类前半句。多个场景并存时，主世界族先遵循用户第一个场景标签；没有场景标签时优先理解“主要场景设在森林”“story takes place in a forest”等明确主场景指令，最后才回退到正文最早出现的肯定地点，并记录证据来源，避免把出发地、序章地点或远景误当主场景。主场景指令本身也继承否定范围，因此“不要把主要场景设在森林，改为城市天台”和英文长句只采用替换后的地点。它还会检查动作隐含道具、多个场景世界族和水下明火等强语义冲突，并将“拉弓需要弓箭”“撑伞需要雨伞”“手机拍摄需要手机”这类无冲突动作依赖软补全到图像与视频 Skill。关系软补全完成后会重新结算关系图：已经进入 Skill 成品的问题转入已解决记录，不再错误显示为待审查，模型风险也按最终未解决问题计算。英文正文只有 `wields a sword`、`reads a scroll` 等明确动作证据才触发关系补全，单独出现的 `sword/scroll/torch` 装饰名词不会污染道具。即使用户明确选了不完整的道具组合，也会保留显式道具并只追加动作明确需要的缺失道具；原始用户标签和 JSON 仍不被改写，也不会把手机拍摄串成额外相机。本地模型、严格风格隔离、设定图、视频优先与标签块默认使用增量融合，普通 API 可保守整理全文。候选失败后按缺锚点、世界族越界、语言、画面结构、分析包装或重复等类型执行单目标定向修复。连续偏好按“任务类型 + 场景世界族”隔离，只在当前分组为空时软应用，不学习运行时随机结果，也不覆盖显式选择、主体、场景和锁定项。
- 剧情规划中的开端、升级和结尾是因果推理，不是要求绘图模型同时画出多个时间点。成品只显示当前动作峰值，过去和未来由衣料余势、道具状态、视线、光线和环境痕迹暗示；正文长短不会改变单帧合同。

## 模型 API 状态

点击节点底部 `模型` 后，必须把 `模型来源` 切换为 `API`；停留在 `Skill` 时不会发送任何 API 请求。切换到不同服务商会写入该服务商的预设地址、模型和 `env:` 密钥引用，并清空旧的额外请求头，避免把认证信息带到其他服务商。切换到 `OpenAI兼容` 或 `自定义` 后，地址、模型和密钥需要重新填写。

`env:变量名` 通常只读取指定变量。兼容旧工作流时，`env:QWEN_TE_API_KEY` 为空会继续尝试当前服务商的标准变量，例如 `OPENAI_API_KEY` 或 `DEEPSEEK_API_KEY`。密钥留空时，命名远程服务商也会检查其预设环境变量；兼容、自定义和本地接口不会自动借用通用密钥。

`API地址` 只接受规范的 `http://` 或 `https://` Base URL，不得包含账号密码、查询参数、片段、反斜杠、转义点段、中文路径或控制字符。`API额外请求头` 支持 JSON 对象或每行 `名称: 值` / `名称=值`；格式错误、重复名称、空值和控制字符会直接报错，认证、Host、Content-Type、Content-Length、Cookie 等受保护字段不能覆盖。

模型面板会显示最近一次运行的 `未启用 / 待调用 / 调用成功 / 部分回退 / 调用已恢复 / 调用失败` 状态。JSON 中 `model_active_fallback_count` 表示最终仍使用 Skill 的输出条数；`model_call_failure_count` 记录历史失败次数，两者含义不同。配置签名同时覆盖服务商、地址、模型、Key 引用和额外 Header，但只输出不可逆摘要，不输出明文认证信息。

视频输出会复用当前本地模型/API连接再调用一次专用润色任务。`video_prompt_model_status` 显示是否采用模型结果，`video_prompt_model_source` 显示实际来源，`video_prompt_required_anchor_count` 显示本次保护的事实锚点数量。模型加载或调用失败时，第 8 个输出仍返回视频 Skill 成品；配置失败的活动回退数量会包含这一路视频输出。

当前主要预设包括 DeepSeek `deepseek-v4-flash`、Groq `openai/gpt-oss-20b`、Claude `claude-haiku-4-5`、Gemini `gemini-2.5-flash`。OpenAI o1/o3/o4/GPT-5 会自动使用兼容的消息角色和 token 参数；DeepSeek V4 默认关闭 thinking；Claude/Gemini 原生接口会映射各自的采样和停止序列字段。API 默认超时为 120 秒；超时、断连、429 和服务端 5xx 会有界重试一次，认证错误与普通 4xx 不重试。用户填写的最大 token 作为每条上限生效，批量请求按条数扩展并封顶 8192，不再静默强制单条至少 1280。批量模型没有按分隔协议返回时，最多 8 条的小批量会自动逐条重试。

## 网页浏览器与提示词搜索

点击终端预览标题栏中的 `浏览器`。弹窗默认打开 `网页浏览器` 页签，可输入 `example.com`、完整 HTTPS 地址或普通搜索词，再点击 `打开`。弹窗打开时只显示本地主页，不会自动访问外部网站。

主浏览区不是 iframe。后端会启动隔离的本机 Microsoft Edge/Chrome/Chromium 无头会话，把实时网页画面传回节点，并把鼠标点击、拖动、滚轮、常用按键、粘贴和中文输入发送到真实浏览器页面。因此 GitHub、Google、百度等拒绝 iframe 的网站也不再受 `X-Frame-Options` 或 CSP 嵌入限制，返回、前进和刷新读取的是真实浏览器历史。交互期间使用低延迟原生尺寸画面，页面稳定后按设备像素比生成高清帧；检测到可见视频或连续变化画面时会自动切换为较低编码开销的动态帧并提高刷新频率，因此 iframe 播放器、Canvas 动画也能降载，暂停或静止后恢复高清静态帧。每帧会跟随网页当前可视视口取图，滚动长页面后不会再误抓页面顶部而出现整帧空白或只剩一条内容。轮询会扣除截图本身的耗时，拖动和滚轮只保留最新待发送事件，静止页面自动降低刷新频率，后台标签页降至最低刷新频率。隔离浏览器会关闭同步、扩展和默认应用等无关后台活动。窗口尺寸或显示缩放变化后，网页视口和点击坐标会自动同步。

内嵌会话默认禁止下载，关闭弹窗或返回本地主页时会关闭对应浏览器进程并清理临时会话目录；如果页面刷新、前端崩溃或网络中断导致关闭请求没有送达，后台会话也会在空闲 20 分钟后自动退出。若当前 Edge/Chromium 被系统策略禁止远程调试，节点会自动诊断失败原因，并用当前网址打开真正的独立可见浏览器窗口，不再停留在灰色失败页；之后点击 `打开` 会继续在这个独立浏览器模式中打开网址。独立窗口支持标签页、下载、登录、证书检查、系统选择器和复杂弹窗，右上角的 `独立浏览器` 按钮也可随时打开当前网址。地址栏右侧箭头仍用于普通新标签页打开当前网址。

入口会拒绝危险协议、带账号密码的网址以及直接输入的本机/内网地址；请求接口还要求本机同源和专用请求头。这只是入口保护，不是完整网络隔离，网页打开后仍可自行跳转或发起网络请求。

Windows 会自动查找 Microsoft Edge、Google Chrome 或 Chromium。需要指定便携 Chromium 时，可在启动 ComfyUI 前设置 `QWEN_TE_BROWSER_EXE` 为可信浏览器可执行文件的绝对路径；只接受 `msedge.exe`、`chrome.exe` 或 `chromium.exe`。插件更新后新增的本机浏览器接口需要完整重启 ComfyUI 才会生效。

切换到 `提示词搜索` 页签，输入画面主题或风格关键词，再点击 `搜索`。节点会从公开提示词来源检索完整提示词，并在在线来源不可用时使用本地标签库组合提示词。

提示词搜索结果不会自动参与生成。选择完整提示词后可执行 `回填提示词`、复制提示词，或明确执行拆分入库。网页只在手动打开后访问；提示词关键词只在点击 `搜索` 后发送到第三方来源，普通生成和仅 Skill 模式不会自动联网。

要启用通用网页搜索，请打开现有的 `online_search_config.json`，只修改其中的 SearXNG 地址和公开回退开关，不要用下面的片段覆盖整个文件：

```text
"searxng_base_url": "https://search.example.com",
"searxng_timeout_seconds": 8,
"public_source_fallback_enabled": false
```

也可在启动 ComfyUI 前设置环境变量 `QWEN_TE_SEARXNG_URL` 临时覆盖配置。SearXNG 返回有效结果后不会继续访问 Civitai 或 Lexica。将 `public_source_fallback_enabled` 设为 `false` 后，SearXNG 不可用或无结果时也不会访问公开来源，而是直接使用本地标签库回退；未配置 SearXNG 时该开关同样适用。

相同关键词的原始搜索样本会短时缓存，重复点击不会反复访问外部来源；标签是否已入库仍会按当前标签库重新计算。成功结果缓存约 3 分钟，全源失败只短暂缓存约 20 秒，网络恢复后无需长时间等待缓存失效。

SearXNG 实例必须启用 JSON 输出（`format=json`），当前只接受无账号信息的 HTTPS 地址，也不发送自定义认证头。本机自签名或企业 CA 可通过 `SSL_CERT_FILE` 或 `REQUESTS_CA_BUNDLE` 指定证书包；纯 HTTP 的 localhost 实例不会连接。公开仓库建议使用环境变量保存私有实例地址，避免误提交内部域名。
